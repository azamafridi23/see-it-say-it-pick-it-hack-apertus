# See It, Say It, Pick It — team Asian Prompters

Our Hack Apertus 2026 entry for Track 2A, the ZHAW challenge *See It, Say It, Pick It*. The project
follows the [Hack Apertus project template](https://github.com/HackApertus/project-template): everything
is in [`track_2a/`](track_2a/), the project root.

```
cd track_2a
cp .env.example .env        # then fill in LLM_API_KEY
make run                    # builds the Docker image and runs our pipeline on the held-out scenes
```

- Write-up: [track_2a/technical_report.md](track_2a/technical_report.md)
- Run guide, with and without Docker: [track_2a/docs/USAGE.md](track_2a/docs/USAGE.md)
